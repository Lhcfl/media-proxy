# Specification

Specifications for the Misskey media proxy.

- [`specification.ja.md`](./specification.ja.md) — 日本語（原文・正式 / original, authoritative）
- [`specification.en.md`](./specification.en.md) — English translation
- [`specification.zh.md`](./specification.zh.md) — 中文翻译

The Japanese file is the source of truth. The translations are provided for
convenience and may lag behind it. Behavior that intentionally differs from
this specification (for example the handling of ICO and unconvertible formats
in this fork) is documented in [`../README.md`](../README.md) and
[`../AGENTS.md`](../AGENTS.md).
